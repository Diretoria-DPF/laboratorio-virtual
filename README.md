# 🧪 Simulador Virtual LAIFT - Química do Cotidiano e Toxicologia

## 📌 Sobre o Projeto
Uma plataforma web interativa desenvolvida para simular reações químicas de alto risco, precipitações toxicológicas e espectroscopia de chama (teste de chama). O projeto foi desenhado sob a ótica da **Sala de Aula Invertida (Flipped Classroom)**, permitindo que os alunos explorem misturas químicas e visualizem resultados de forma 100% segura antes da prática real em laboratório.

Este simulador é parte integrante do Projeto de Extensão focado em "Toxicologia Visual e Química do Cotidiano" da **Liga Acadêmica LAIFT**.

## ⚙️ Funcionalidades Principais
* **Mesa de Reações Interativa:** Cruzamento de diversos cátions metálicos (incluindo metais pesados como Pb²⁺, Cd²⁺, Sb³⁺) com variados agentes precipitantes e solventes.
* **Feedback Visual e Toxicológico:** Animações dinâmicas que ilustram explosões, formação de vapores tóxicos (ex: gás cloramina, gás cloro) e precipitação com texturas realistas.
* **Espectroscopia de Chama (Teste de Fogo):** Simulador de ignição para observação da assinatura atômica (cores emitidas) de sais submetidos a altas temperaturas em um cadinho de porcelana.
* **Gestão de Vidrarias:** Alternância entre Tubo de Ensaio e Béquer, simulando a manipulação real de volumes e instrumentos de bancada.
* **Diário de Bordo Integrado:** Retorno em tempo real sobre a química por trás de cada reação para fixação teórica imediata.

## 🔬 Contexto Acadêmico
O simulador foi criado como ferramenta preparatória para um laboratório presencial. O objetivo é reduzir o desperdício de reagentes de alto custo e zerar os riscos de acidentes durante a curva inicial de aprendizado.
